# G1 robot model

`g1_body29_hand14.urdf` and its 49 STL meshes are packaged for PATH's
Pinocchio/CasADi arm IK and perception geometry. The file is pinned to
[`unitreerobotics/xr_teleoperate` commit `f7bdf9c`](https://github.com/unitreerobotics/xr_teleoperate/tree/f7bdf9ce4819a050010ac745c720062cde9a2f63/assets/g1)
and retains its upstream [Apache-2.0 license](LICENSE.xr_teleoperate).

Runtime defaults point here through `PATH_G1_ROOT/assets/robot`; no checkout
outside PATH-G1 is required for the robot description or meshes.
